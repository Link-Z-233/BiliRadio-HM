# Feature Specification: v0.8-part2 设置页分组重组与选项弹窗公共组件

**Status**: Draft
**Input**: User description: "设置页新填一个分组，把历史同步、取消收藏提醒、单集插入位置等内容放在一起；通用分组重命名为系统分组，历史记录移出该分组；两项默认音质设置弹窗标题固定、未登录/非会员通知放标题底下固定、底部过冲部分背景覆盖（此前历史面板出过同类 bug），并把这种弹窗提成公共组件" + 再优化批: "导入和导出功能合并后放入系统分组；公共组件底部留白过大，浅色模式下背景透明度过高；播放历史独立成单独分组；历史同步与取消收藏提醒挪回账号分组（独立同步组取消）；退出登录改为账号用户行右端的「登出」两字胶囊按钮；设置页滚动内容底部大段空白（遗留的迷你播放器净空——设置层已物理覆盖胶囊，净空无对应可见物）；主题色色板行均匀分布（自定义色需求已放弃，色板集合不变）" + 真机反馈批: "底部弹窗（音质/单集插入/订阅管理/关于）内容直接铺到窗口物理底部，最后一行被系统手势指示条叠压、点击被系统手势区吞掉——弹窗内容底部避让指示条（navBarHeight）" + 关于页批: "关于页去掉「完成」按钮，条目保持紧凑，一屏完整展示全部内容"

## Overview

设置页分组结构重组最终态：历史同步与取消收藏提醒留在账号分组（不设独立同步组）；退出登录由独立危险行改为用户行右端「登出」胶囊按钮（ListRow 新增行尾槽位）；播放历史独立为无标题单行卡片；单集插入位置回归播放设置组末行；「通用」改名「系统」并收入订阅管理合并行（点击弹选项弹窗，独立订阅管理分组删除）；设置页滚动内容底部遗留的迷你播放器净空删除（设置层物理覆盖胶囊，净空表现为纯空白）；外观组主题色色板行改为均匀分布（色板集合与选择行为不变）。新建 OptionSheet 选项弹窗公共组件：固定标题、可选固定通知、可滚动选项列表、高度内容自适应（消底部留白）、背景铺满全弹窗（浅色不透明度与深色对齐，修背景分层），音质、单集插入位置、订阅管理三处弹窗共用。全部设置项持久化键与行为零变化。

## User Scenarios & Testing

### User Story 1 - 分组重组：账号分组收拢 + 播放历史独立卡片 (Priority: P1)

登录用户打开设置页：账号分组含用户行（右端「登出」胶囊）、历史同步、取消收藏提醒；账号分组之后为播放历史无标题单行卡片；单集插入位置回到播放设置组末行。未登录时账号分组仅显示登录控件与 Cookie 块。

**Why this priority**: 分组重组是本轮结构变化核心，本故事定义最终分组形态。

**Independent Test**: 登录/未登录两态打开设置页，逐分组核对行归属、登出按钮位置与各开关行为。

**Acceptance Scenarios**:

1. **Given** 已登录打开设置页，**When** 查看，**Then** 分组结构为 账号 → 播放历史（无标题单行卡片）→ 播放设置 → 外观 → 系统，无独立同步分组
2. **Given** 已登录，**When** 查看账号分组，**Then** 依次为 用户行（头像/昵称/大会员徽标 + 右端「登出」胶囊）、历史同步、取消收藏提醒（开关文案与行为不变）
3. **Given** 已登录，**When** 点「登出」胶囊，**Then** 弹出退出确认弹窗，确认后登出（confirmLogout 行为不变）；点胶囊不触发行本身点击
4. **Given** 未登录，**When** 查看，**Then** 账号分组仅显示登录控件与 Cookie 块，无历史同步/取消收藏提醒/登出胶囊
5. **Given** 播放设置分组，**When** 查看，**Then** 含 启动时自动播放、后台打断续播、Wi-Fi 默认音质、移动网络默认音质、音质通知、仅在 Wi-Fi 环境播放、单集插入位置（末行，无悬空分割线）
6. **Given** 播放历史卡片，**When** 点击，**Then** 打开播放历史面板（行为不变）
7. **Given** 任一被移动的设置项，**When** 开关或选择，**Then** 持久化键与读写行为与重组前一致
8. **Given** 滚动到设置页底部，**When** 查看，**Then** 「系统」分组下方仅余常规留白 + 系统导航条高度，无大段空白（胶囊净空删除）
9. **Given** 外观组主题色色板行，**When** 查看，**Then** 6 个预设色圆点在行内均匀分布（等宽槽位铺满整行），选中态描边与选择行为不变

### User Story 2 - 订阅管理合并入「系统」分组 (Priority: P2)

「订阅管理」独立分组删除；「系统」分组头部新增「订阅管理」行（副标题说明、箭头），点击弹出选项弹窗，内含「导出订阅」「导入订阅」两个选项，点选执行对应操作。系统分组依次为 订阅管理、日志查询、关于。

**Why this priority**: 合并消掉单行数最少的独立分组，系统分组成为数据与工具的统一收纳。

**Independent Test**: 点系统分组「订阅管理」行，弹窗两选项分别触发导出分享与导入选择器，行为与合并前一致。

**Acceptance Scenarios**:

1. **Given** 打开设置页，**When** 查看，**Then** 「订阅管理」独立分组不再出现；「系统」分组依次含 订阅管理、日志查询、关于
2. **Given** 点「订阅管理」行，**When** 弹窗打开，**Then** 弹窗标题「订阅管理」，选项为 导出订阅、导入订阅，无选中态、无通知区
3. **Given** 弹窗内点「导出订阅」，**Then** 执行导出分享链路（空列表拦截、分享面板），弹窗关闭，行为与合并前一致
4. **Given** 弹窗内点「导入订阅」，**Then** 拉起文档选择器，导入校验/合并/toast 行为与合并前一致
5. **Given** 弹窗打开时按系统返回键，**Then** 优先关闭弹窗（返回链一致）

### User Story 3 - OptionSheet 公共组件与弹窗体验 (Priority: P1)

音质弹窗、单集插入位置弹窗、订阅管理弹窗共用 OptionSheet 组件：标题固定顶部；状态通知（未登录/非会员）固定标题下方；选项列表在剩余区域滚动；弹窗高度随内容自适应（短内容无大片底部留白，超限时列表内部滚动）；背景铺满整个弹窗区域，浅色模式不透明度与深色对齐（90% alpha），深浅色均无背景分层。

**Why this priority**: 组件化 + 留白/透明度修正直接决定三处弹窗的可用性与观感。

**Independent Test**: 未登录/非会员/大会员三态打开音质弹窗核对通知与高度；深浅色滚动核对背景无分层；订阅管理/单集插入弹窗核对紧凑高度与同款视觉。

**Acceptance Scenarios**:

1. **Given** 未登录，**When** 点「Wi-Fi 默认音质」，**Then** 弹窗标题固定，通知「未登录时最高 64K，登录后可用更高音质」固定标题下方，列表仅「最高」「64K」，弹窗高度贴合内容无大片留白
2. **Given** 已登录非会员，**When** 点音质行，**Then** 通知「192K/Hi-Res/杜比需大会员」固定标题下方
3. **Given** 已登录大会员，**When** 点音质行，**Then** 无通知区，全部档位可见
4. **Given** 选项超出弹窗可视高度，**When** 上下滚动（含边界过冲），**Then** 列表滚动，标题与通知保持原位，过冲区域被弹窗背景覆盖
5. **Given** 浅色模式，**When** 打开任一选项弹窗，**Then** 面板背景近实底（90% alpha），页面内容不透出，与深色模式观感对齐
6. **Given** 当前档位/当前选项，**When** 查看列表，**Then** 选中项强调色 + ✓（订阅管理弹窗无选中态），点选即生效并关闭

### Edge Cases

- 未登录时账号分组仅显示登录控件与 Cookie 块（历史同步/取消收藏提醒/登出胶囊均不显示）
- 「登出」胶囊点击不触发行点击（子组件消费触摸事件）
- 选项列表不足一屏时无可滚动过冲，弹窗高度贴合内容
- 选项内容超过屏高时列表内部滚动，标题与通知仍固定
- 弹窗打开时系统返回键优先关闭弹窗（三个弹窗全覆盖）
- 深色/浅色模式下背景覆盖与不透明度效果一致
- 底部弹窗（音质/单集插入/订阅管理/关于）最后一行避让手势指示条，点击不被手势区吞掉；无指示条设备退化为常规留白
- 「关于」弹窗移除「完成」按钮后经拖拽条或系统返回键关闭（showAbout 纳入返回链）

## Requirements

### Functional Requirements

- **FR-001**: 设置页分组结构 MUST 为 账号 → 播放历史（无标题单行卡片）→ 播放设置 → 外观 → 系统（无独立同步分组）
- **FR-002**: 播放历史 MUST 为无标题单行卡片（账号组之后），图标入口行为不变
- **FR-003**: 账号分组 MUST 依次含 用户行、历史同步、取消收藏提醒（两开关仅登录时显示，文案与行为不变）
- **FR-004**: 退出登录 MUST 改为用户行右端「登出」两字胶囊按钮（中性淡底 + danger_red 文字，仅登录态显示），点击触发既有确认弹窗（confirmLogout 行为不变）；原独立「退出登录」危险行 MUST 删除
- **FR-005**: ListRow MUST 新增行尾自定义槽位（@BuilderParam），「登出」胶囊经此槽位注入用户行，不影响其他行默认渲染
- **FR-006**: 播放设置分组 MUST 依次含 启动时自动播放、后台打断续播、Wi-Fi 默认音质、移动网络默认音质、音质通知、仅在 Wi-Fi 环境播放、单集插入位置（末行），无悬空分割线
- **FR-007**: 「系统」分组 MUST 依次含 订阅管理、日志查询、关于
- **FR-008**: 订阅管理 MUST 合并为系统分组一行（副标题「导出或导入订阅备份」、箭头）；点击弹出 OptionSheet 弹窗（标题「订阅管理」、选项 导出订阅/导入订阅、无选中态、无通知）；独立订阅管理分组 MUST 删除；导出/导入行为不变
- **FR-009**: OptionSheet 组件 MUST 提供 固定标题 + 可选固定通知 + 可滚动选项列表 三段结构，选项行渲染内聚（选中 ✓ + 强调色，无选中态时不显示 ✓）
- **FR-010**: 选项弹窗高度 MUST 内容自适应（短内容贴合、无大片底部留白；超限时列表内部滚动、标题与通知固定）
- **FR-011**: 弹窗背景 MUST 覆盖整个弹窗区域（含滚动过冲与余白）；浅色模式 sheet_background 不透明度 MUST 提升至 90% alpha（与深色对齐），深浅色均无背景分层
- **FR-012**: Wi-Fi/移动网络音质弹窗 MUST 使用 OptionSheet：标题按编辑目标、三态通知固定标题下方、档位过滤与 ✓ 高亮逻辑不变
- **FR-013**: 单集插入位置弹窗 MUST 使用 OptionSheet：选项与持久化行为不变
- **FR-014**: 系统返回键 MUST 优先关闭三个选项弹窗（registerSettingsBack 全覆盖）
- **FR-015**: 全部设置项持久化键、默认值、读写行为 MUST 与重组前完全一致
- **FR-016**: 设置页滚动内容底部 padding MUST 为 navBarHeight + 常规留白令牌，MUST NOT 含 MINI_PLAYER_CLEARANCE（设置层物理覆盖迷你播放胶囊，净空无对应可见物；对齐日志页覆盖层模式）
- **FR-017**: 外观组主题色色板行 MUST 均匀分布（每个色板圆点槽位等宽铺满整行，沿用外观模式行的等分模式）；色板集合、选中态描边与选择行为 MUST 不变
- **FR-018**: 底部选项弹窗（OptionSheet 根节点）与关于弹窗内容底部 MUST 避让系统手势指示条（navBarHeight + 留白令牌），最后一行点击热区 MUST NOT 被系统手势区吞掉；无指示条设备（navBarHeight=0）退化为纯留白令牌，无害
- **FR-019**: 「关于」弹窗「完成」按钮 MUST 移除（拖拽条与系统返回键关闭），showAbout MUST 纳入 registerSettingsBack 返回链；核心功能与项目地址条目 MUST 保持紧凑文本行，弹窗内容 MUST 一屏完整展示

### Key Entities

- **设置分组**: 设置页卡片分组（账号 / 播放历史卡片 / 播放设置 / 外观 / 系统）
- **选项弹窗组件**: 底部弹出的选择器/动作菜单，属性含 标题、可选通知、选项集合、选中态（可空），点选即生效并关闭

## Success Criteria

### Measurable Outcomes

- **SC-001**: 重组后设置页全部功能项可达且行为与重组前一致，无丢失项、无空分组
- **SC-002**: 未登录、非会员、大会员三态下音质弹窗标题与通知均固定，列表滚动时无元素位移
- **SC-003**: 三个选项弹窗在深浅色模式下任意滚动状态（含过冲、余白）无背景色差分层
- **SC-004**: 短内容弹窗高度贴合内容（无可感知的大片底部留白）；三处弹窗共用同一组件实现

## Assumptions

- 单集插入位置回归播放设置组末行（本轮重组前的原位），「仅在 Wi-Fi 环境播放」恢复分割线
- 「登出」胶囊具体尺寸/圆角取项目现有令牌对齐（高约 32、胶囊圆角、TOKEN_FONT_BODY_S 字号），观感可在真机自查后微调
- 订阅管理合并行的图标从 sys.symbol 现有条目选取（导入导出语义，实施时以 sysResource.js 校验存在性）
- 弹窗继续使用底部半模态弹出形态；高度策略由固定百分比改为内容自适应（SheetSize.FIT_CONTENT）
- 播放设置分组内的音质通知文案维持现状
- 应用版本号本轮不动（维持 0.8.0）
- 历史同步、取消收藏提醒维持仅登录可见语义（不置灰）
