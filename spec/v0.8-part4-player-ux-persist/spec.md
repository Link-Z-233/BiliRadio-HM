# Feature Specification: 播放页 UX 反馈修复 + 指定队列持久化

**Input**: 真机反馈：随机模式「下一首播放」跨重启未生效（根因：指定名单不持久化）+ 播放页一组 UX 问题（封面按钮可见性、选择页形态、播放顺序图标、详情排版、按钮换位）+ 源页多选/文案微调；模拟器实测反馈：底栏四菜单（倍速/定时/音质/播放顺序）选项统一 ListRow 行列表、浮窗底色与播放列表透明度统一。

## Overview

本轮完成两件事：一是把「下一首播放」的指定名单随播放列表持久化，使其跨应用重启有效（此前为内存态，冷启动即丢失）；二是按真机反馈修复播放页与源页的一组 UX 问题——封面「视频」按钮在浅色封面下不可见、五个选择面板在窄屏下应为低高度底部浮窗、播放顺序选项缺图标、详情简介排版过紧且滚动条压字、播放顺序与定时按钮换位、源页多选按钮计数冗余与「队列末播放」文案歧义；底栏四菜单（倍速/定时/音质/播放顺序）选项统一为 ListRow 行列表，浮窗面板底色与播放列表（队列）面板玻璃公式统一（透明度一致）。

## User Scenarios & Testing

### User Story 1 - 指定名单跨重启有效 (Priority: P1)

随机播放模式下，用户从源页或队列面板设置「下一首播放」后，即使应用被杀掉重启，当前曲目播完仍优先播放指定曲目。

**Why this priority**: 本轮直接动因——真机日志证实指定登记与消费链路正常，唯一失效场景是冷启动丢失内存态名单；不持久化则用户感知的「未生效」无法根除。

**Independent Test**: 随机模式设置「下一首播放」→ 杀应用重启 → 播完当前曲目 → 自动播放指定曲目。

**Acceptance Scenarios**:

1. **Given** 随机模式且已设置指定曲目 A，**When** 杀掉应用后重启并播完当前曲目，**Then** 自动播放曲目 A。
2. **Given** 已设置指定曲目 A、B（A 在前），**When** 重启后播完当前曲目，**Then** 先播 A 再播 B（顺序保留）。
3. **Given** 重启前指定曲目 A 已被移出队列，**When** 重启恢复，**Then** 名单中 A 被过滤丢弃，其余指定条目照常生效。

---

### User Story 2 - 封面「视频」按钮任意封面下可见 (Priority: P2)

播放页封面右下角的「视频」按钮（跳转原视频）在纯白等浅色封面下与背景融为一体不可见；改为深色半透明底+白色前景后任意封面明度下清晰可辨。

**Why this priority**: 功能入口不可见等同于功能不可达。

**Independent Test**: 播放一首纯白封面的曲目，封面右下「视频」按钮一眼可辨、可点击。

**Acceptance Scenarios**:

1. **Given** 当前曲目封面为纯白/浅色，**When** 播放页展开，**Then** 「视频」按钮轮廓与文字清晰可辨。
2. **Given** 当前曲目封面为深色，**When** 播放页展开，**Then** 按钮仍可辨识（白色前景可读）。

---

### User Story 3 - 窄屏选择面板改为低高度底部浮窗 (Priority: P2)

窄屏（宽度 < 600vp，即现有 isWide 断点）下，底部操作行（倍速/播放顺序/定时/音质）唤起的五个选择面板（倍速、播放顺序、定时关闭、自定义定时、音质选择）从屏幕居中弹窗改为内容自适应高度的底部浮窗，与设置页既有浮窗交互一致；宽屏保持现状居中弹窗。四个菜单（倍速/定时/音质/播放顺序）的选项统一为 ListRow 行列表；浮窗面板底色与播放列表（队列）面板玻璃公式统一（sheet 背景透明 + sheet_panel_background + backdropBlur，透明度一致）。

**Why this priority**: 居中大弹窗在手机上遮挡播放页主体且操作动线长；项目已有成熟的 bindSheet 底部浮窗先例。

**Independent Test**: 窄屏设备分别点底栏五个入口，每个面板均为贴底、高度包住内容的浮窗，点遮罩/下拉可关闭；四菜单选项均为 ListRow 行列表；浮窗底色与队列面板一致；宽屏设备同入口仍为居中弹窗。

**Acceptance Scenarios**:

1. **Given** 窄屏播放页，**When** 点击底栏「倍速」，**Then** 倍速面板以底部浮窗呈现，高度贴合内容。
2. **Given** 窄屏播放页打开任一选择浮窗，**When** 下滑或点遮罩，**Then** 浮窗关闭，回到播放页。
3. **Given** 宽屏（≥600vp）播放页，**When** 点击同入口，**Then** 保持现状居中弹窗形态。
4. **Given** 窄屏播放页打开倍速/定时/音质任一菜单，**When** 查看选项，**Then** 选项为 ListRow 行列表（选中项主题色高亮 + 行尾 ✓），面板底色观感与播放列表面板一致（同款玻璃公式）。

---

### User Story 4 - 详情简介排版与滚动条 (Priority: P2)

播放页展开的详情 sheet（标题/统计/简介）内容过紧：加大边距与行高；滚动条不再压在简介文字上。

**Why this priority**: 简介是详情 sheet 的主体内容，可读性直接影响使用。

**Independent Test**: 展开一首带长简介的曲目详情，简介区边距舒展、行距不挤，滚动时滚动条位于文字右侧留白处。

**Acceptance Scenarios**:

1. **Given** 曲目带多行长简介，**When** 展开详情 sheet，**Then** 简介区水平/垂直边距与行高明显大于现状，阅读不局促。
2. **Given** 简介超出可视高度，**When** 滚动简介，**Then** 滚动条与文字不重叠。

---

### User Story 5 - 播放顺序选项前置图标 (Priority: P3)

播放顺序选择面板的四个模式选项（顺序播放/倒序播放/随机播放/单曲循环）在文字前显示对应图标，与底栏模式按钮同源：顺序=order_play、倒序=order_play 旋转 180°、随机=shuffle、单曲循环=repeat_1。

**Why this priority**: 图标与底栏模式图标建立视觉对应，降低辨认成本。

**Independent Test**: 窄屏/宽屏分别打开播放顺序面板，每个选项文字前有对应图标，倒序图标旋转 180°。

**Acceptance Scenarios**:

1. **Given** 打开播放顺序面板，**When** 查看四个选项，**Then** 每项图标与该模式的底栏图标一致，倒序项旋转 180°。

---

### User Story 6 - 播放顺序与定时按钮换位 (Priority: P3)

底部操作行按钮顺序由「倍速、播放模式、音质、定时、队列」改为「倍速、定时、音质、播放模式、队列」。

**Why this priority**: 用户指定的操作频率排序。

**Independent Test**: 打开播放页底栏，五个按钮依次为 倍速、定时、音质、播放模式、队列，各自功能不变。

**Acceptance Scenarios**:

1. **Given** 播放页底栏，**When** 查看/点击五个按钮，**Then** 顺序为新序且各按钮触发的面板正确。

---

### User Story 7 - 「队列末播放」文案统一为「添加至队列末」 (Priority: P3)

源页多选按钮「队列末播放」与设置页「单曲插入位置」选项中的「队列末播放」统一改为「添加至队列末」，消除「队列末=播放顺序承诺」的歧义（随机模式下队列位置不决定播放顺序）。

**Why this priority**: 现文案与随机模式实际语义不符，易误导。

**Independent Test**: 全应用检索无「队列末播放」字样；源页多选底部按钮与设置页选项均显示「添加至队列末」。

**Acceptance Scenarios**:

1. **Given** 源页进入多选，**When** 查看底部按钮，**Then** 显示「添加至队列末」（无计数）。
2. **Given** 设置页单曲插入位置选项，**When** 查看，**Then** 选项文案为「添加至队列末」。

---

### User Story 8 - 源页多选按钮去除选中计数 (Priority: P3)

源页多选底部「添加至队列末」「下一首播放」按钮不再显示 (N) 计数——多选顶栏已有「已选 N 项」。

**Why this priority**: 信息重复；顶栏为准。

**Independent Test**: 多选选中若干条，底部两按钮只显示功能文字，顶栏显示「已选 N 项」。

**Acceptance Scenarios**:

1. **Given** 多选选中 3 条，**When** 查看底部按钮与顶栏，**Then** 按钮无计数、顶栏显示「已选 3 项」。

---

### Edge Cases

- 重启恢复时指定条目已不在队列（被移除/清空后重建）→ 名单按 key 过滤丢弃该条，剩余条目顺序不变。
- 旧版播放列表文件无指定名单字段 → 按空名单加载，不报错。
- 指定条目为多 P（复合 key 含 page）→ 复合键原样持久化与恢复。
- 指定名单消费（播完兑现/播放时移除/手动移除/队列清空）后 → 持久化内容同步更新，重启不复活已消费条目。
- 窄屏打开选择浮窗后旋转至宽屏（或反向）→ 已打开面板即时转为新断点形态（浮窗↔居中弹窗无缝接管），内容与选中状态不丢失。
- 定时「自定义」二级 picker 与一级定时面板的返回关系在浮窗化后保持（取消/遮罩关闭回一级，确认直接关闭）。

## Requirements

### Functional Requirements

- **FR-001**: 「下一首播放」指定名单 MUST 随播放列表持久化文件一并保存（有序 key 列表），并在冷启动恢复时重建为指定队列。
- **FR-002**: 恢复时 MUST 仅保留队列中仍存在的 key（按 key 匹配过滤），被过滤条目不阻断其余条目恢复。
- **FR-003**: 旧格式持久化文件（无指定名单字段）MUST 正常加载为空名单，无错误提示。
- **FR-004**: 指定名单的登记、消费、移除各既有路径 MUST 同步持久化，重启后不出现已消费/已移除条目复活。
- **FR-005**: 封面「视频」按钮 MUST 采用深色半透明底+白色前景，在纯白与纯黑封面下均清晰可辨；底色/前景色值 MUST 走 Constants/色资源 token。
- **FR-006**: 窄屏（<600vp）下倍速/播放顺序/定时关闭/自定义定时/音质五个选择面板 MUST 以系统底部浮窗（内容自适应高度）呈现，支持拖拽条关闭、遮罩点击关闭；宽屏 MUST 保持现状居中弹窗。
- **FR-012**: 倍速/定时/音质/播放顺序四菜单选项 MUST 为 ListRow 行列表（选中项主题色高亮 + 行尾 ✓）。定时面板与底层单选模型对齐：预设/自定义/播完暂停均为单选行（激活档位行尾 ✓，自定义激活时行尾显示设定时长），播完暂停点击武装并关闭面板，选任一项取代既有定时；自定义为箭头行、取消定时为危险行。定时入口（底栏表盘图标）在播完暂停武装时 MUST 于图标旁显示主题色 pause 小图标提醒（与倒计时剩余数字同位同字号）。
- **FR-014**: 定时面板选档生效 MUST 晚于面板关闭动画（启动/武装/取消在面板收起后执行），收起过程 MUST NOT 闪现「取消定时」危险行（条件行插入被退出动画带出的闪红）。
- **FR-013**: 五个选择浮窗面板底色 MUST 与播放列表（队列）面板玻璃公式统一：bindSheet 背景透明、遮罩 `mask_heavy`（与 GlassSheet 一致），内容根 `sheet_panel_background` + `backdropBlur(GLASS_BLUR)` + 顶部分隔线；宽屏 overlay 卡片形态维持现状。
- **FR-007**: 播放顺序面板每个选项 MUST 在文字前显示该模式对应图标（与底栏模式图标同源，倒序旋转 180°）。
- **FR-008**: 详情 sheet 简介区 MUST 加大边距与行高；滚动条 MUST 不与简介文字重叠（留出滚动条专属空间）。
- **FR-009**: 底部操作行按钮顺序 MUST 为：倍速、定时、音质、播放模式、队列；各按钮功能与现状一致。
- **FR-010**: 全部用户可见的「队列末播放」文案 MUST 改为「添加至队列末」（源页多选按钮、设置页单曲插入位置选项及同文案出现处）。
- **FR-011**: 源页多选底部「添加至队列末」「下一首播放」按钮 MUST NOT 显示选中计数 (N)。

### Key Entities

- **指定播放名单**: 有序复合键列表（bvid+page），随机模式下播完兑现的消费顺序依据；本轮起随播放列表持久化文件存储，生命周期与队列文件一致。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 随机模式设置「下一首播放」→ 杀应用重启 → 播完当前曲目自动播放指定曲目（单条与多条顺序场景均成立）。
- **SC-002**: 纯白封面下「视频」按钮轮廓与文字一眼可辨。
- **SC-003**: 窄屏五个选择面板均为低高度底部浮窗且可关闭；四菜单选项为 ListRow 行列表；浮窗底色与队列面板透明度一致；宽屏形态与改动前一致。
- **SC-004**: 详情简介区边距/行高肉眼可见改善，滚动条不压字。
- **SC-005**: 全应用用户可见文案无「队列末播放」；源页多选按钮无计数；底栏按钮为新序。
- **SC-006**: 旧播放列表文件升级后首次启动无异常，指定名单功能可用。

## Assumptions

- 指定名单持久化复用播放列表持久化文件（playlist.json 同文件新增字段），不另立存储。
- 窄屏判定沿用现有 isWide 断点（600vp），不引入设备类型判定。
- 底部浮窗采用系统 bindSheet（FIT_CONTENT、BOTTOM、dragBar），与设置页/详情 sheet 同机制。
- 「视频」按钮深色底色值与白色前景色入 token（Constants/色资源），禁裸值硬编码。
- 定时「自定义」picker 内容复用现状；倍速/定时/音质面板选项改 ListRow 行列表（与播放顺序面板、设置页行视觉统一）。
- 队列面板（list_bullet 入口）已是独立 sheet，不在本轮五个面板改造范围内。
